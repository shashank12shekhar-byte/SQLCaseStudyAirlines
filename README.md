# SQLCaseStudyAirlines
This SQL project analyses airline, airport, and passenger data which includes queries to answer business questions such as busiest airports, ticket sales, passenger loyalty, and airline revenue.

Tech Stack:

This SQL project is compatible with (PostgreSQL/MySQL)

Key Concepts: Joins, Aggregations, Window Functions, CTEs, CASE statements

Power BI – Interactive dashboards, KPIs, slicers, and visual storytelling.
